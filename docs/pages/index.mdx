# Santekno Go SDK

A MIT-licensed, generics-first Go utility SDK spanning 20+ sub-packages — HTTP resilience,
structured logging, JWT auth, validation, observability, and first-class Indonesian locale support.

## Install

```bash
go get github.com/santekno/sdk
```

## Packages

| Package | Description |
|---------|-------------|
| [httpx](/packages/httpx) | Resilient HTTP client with retry and circuit breaker |
| [logx](/packages/logx) | Structured logger interface |
| [timex](/packages/timex) | Indonesian date/time and business calendar |
| [validx](/packages/validx) | NIK, NPWP, IDR validation |
| [jwtx](/packages/jwtx) | JWT sign/verify |
| [hashx](/packages/hashx) | Argon2id password hashing |
| [cryptox](/packages/cryptox) | AES-GCM, ChaCha20, RSA, Ed25519 |
