# httpx — Resilient HTTP Client

## Install

```bash
go get github.com/santekno/sdk/httpx
```

## Quickstart

```go
client := httpx.New(
    httpx.WithTimeout(5*time.Second),
    httpx.WithRetries(3),
)

var result MyResponse
if err := client.GetJSON(ctx, "https://api.example.com/data", &result); err != nil {
    log.Fatal(err)
}
```

## Default Values

| Setting | Default |
|---------|---------|
| Timeout | 30s |
| Retries | 3 |
| Retry methods | GET, HEAD, OPTIONS |
| Retry on status | 503, 502, 504 |
| Breaker threshold | 5 consecutive failures |
| Breaker timeout | 10s |

## API Reference

### `New(opts ...Option) *Client`

Creates a new Client with the given options applied on top of defaults.

### `(c *Client) GetJSON(ctx, url, dst) error`

Sends GET, decodes JSON response body into `dst`.

### `(c *Client) PostJSON(ctx, url, body, dst) error`

Sends POST with JSON body, decodes JSON response into `dst`.

### `(c *Client) Do(ctx, req) (*http.Response, error)`

Low-level method with full retry+circuit-breaker logic.

## Options

| Option | Description |
|--------|-------------|
| `WithTimeout(d)` | Request timeout |
| `WithRetries(n)` | Max retry attempts |
| `WithLogger(l)` | Attach a `logx.Logger` |
| `WithBearerToken(t)` | Set Authorization header |
| `WithAPIKey(k)` | Set ApiKey Authorization |
| `WithBreakerThreshold(n)` | Failures before breaker trips |

## Performance

`httpx.Client.Do` adds ≤ 1 µs overhead over raw `http.Client.Do`.
