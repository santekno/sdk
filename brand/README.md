# Brand Assets

This directory contains official Santekno Go SDK brand assets.

## Directory Structure

```
brand/
├── colors/
│   └── tokens.json        # Design tokens (colors, surfaces, states)
├── logo/
│   └── README.md          # Logo SVG guidelines
└── banners/
    └── README.md          # Banner / social preview guidelines
```

## Social Preview

The GitHub social preview image is located at `banners/github-social-preview.png`
(to be added by the brand lead). It is referenced in the repository settings under
**Settings → Social Preview**.

## Color Palette

| Token | Value | Usage |
|-------|-------|-------|
| `color.brand.primary` | `#00C2A8` | Primary actions, links |
| `color.brand.primary-dark` | `#009B87` | Hover / pressed states |
| `color.text.primary` | `#1A202C` | Body text |
| `color.state.error` | `#E53E3E` | Error states |

See `colors/tokens.json` for the complete token set.
