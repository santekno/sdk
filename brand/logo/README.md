# Logo Assets

Logo SVG files will be added by the brand lead.

Expected files:
- `logo.svg` — full horizontal logo (color)
- `logo-dark.svg` — full horizontal logo (white, for dark backgrounds)
- `icon.svg` — icon only (square, 512×512)
- `icon-dark.svg` — icon only (white, for dark backgrounds)

## Usage Guidelines

- Minimum size: 120px wide for full logo, 32px for icon
- Clear space: equal to the height of the "S" glyph on all sides
- Do not modify colors, proportions, or add effects
- Primary color: `#00C2A8` (see `../colors/tokens.json`)
